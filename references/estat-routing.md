# e-Stat逆引き

地域背景の補助情報が回答に必要な場合だけ使用する。個人の支援資格、診断、重症度、給付可否には使用しない。

## 手順

1. ケースから必要な統計概念を1つ選び、`search_statistics`で統計表を検索する。
2. 候補の統計表IDを`get_statistic_meta`へ渡す。
3. 都道府県・市区町村名、時点名、項目名を`keyword`に指定して分類コードを逆引きする。
4. 確認したコードだけを`get_statistic_data`へ渡す。コードを推測しない。
5. 統計名、対象地域、対象時点、単位、取得日時を示す。

## 停止条件

- 支援候補の確認に地域統計が不要なら呼び出さない。
- 適切な統計表や分類コードが見つからなければ「統計未確認」とし、検索を繰り返さない。
- 一回の回答で扱う統計テーマは原則1つに絞る。
